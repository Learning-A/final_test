# 正式轮次日志约定

最新目标为8个存储节点各自的12 OSS读写总IOPS；client7414是CPU服务运行位置和辅助观测客户端。当前只开展冒烟，不进入正式轮次；下文此前固定client7414为target的说明已被覆盖。

最新固定正式对象为client7414总NFS IOPS；五类负载各3轮正式，15轮独立保留。准确率只排除实际IOPS为零的窗口，全部正值纳入并披露排除量。其他OSS/客户端不能替换正式target。分轮与当前状态以[采集前准备与确认清单](采集前准备与确认清单.md)为准。

每轮单独目录，包括 `round_manifest.json`、`selection.json`、`clock_alignment.json`、`predictions.jsonl`、`windows.jsonl`。原始计数和处理质量另存于关联采集目录。日志结束后登记 SHA256；`verify` 不会为未封存日志给出通过结论。

`selection.json` 是正式三轮前冻结的选择副本。必须包含目标 scope/entity/component、模型 SHA256、协议哈希、负载和提交版本、训练及验证轮清单、冻结 epoch_ns。正式轮不能出现在训练或验证清单中。

`round_manifest.json` 结构模板在 `config/round_manifest.template.json`。模板中的 null 和待填写值必须由真实日志、模型与证据替换，不能通过手填 `passed` 绕过复算。`selection_hash` 为规范化JSON内容的SHA256，`log_sha256` 和时钟证据 SHA256 为文件原始字节的哈希，两者用途不同。

计时零点采用本轮开始记录时刻 `recording_start`；若负载工具能提供更精确的实际首I/O，也可使用 `tool_first_io`。两者都写入本轮结构化 JSON（如 `first_io.json`）并登记字节 SHA256，`verify` 检查事件与 t0 一致。记录起点不被解释为首个实际 I/O，负载工具日志中的更早/更晚事件仍须原样保留。

预测由 `idfs_lab.journal.PredictionJournal` 记录，两条事件组成一项可审计输出：

```json
{"event":"prediction","target":{"scope":"cluster_oss","entity":"all","component":"total"},"window_start_ns":0,"window_end_ns":1000000000,"feature_end_ns":0,"features_available_ns":0,"compute_start_ns":0,"issue_epoch_ns":0,"prediction_iops":0,"model_sha256":"实际校验值","protocol_hash":"实际协议哈希"}
{"event":"prediction_commit","target":{"scope":"cluster_oss","entity":"all","component":"total"},"window_start_ns":0,"committed_epoch_ns":0}
```

示例的0只说明字段，不能作为正式数据。预测完成和落盘确认必须早于窗口起点。特征结束时刻不可晚于预测，数据可用时刻不可晚于计算开始；出现迟发、重复或缺少确认事件直接记录错误，不删除有问题的窗口以抬高准确率。

`windows.jsonl` 由100ms计数处理生成，字段为 scope、entity、window_start_ns、window_end_ns、complete、n_ticks、read_iops、write_iops、total_iops、available_epoch_ns。全OSS聚合需要该网格全部96个OSS有效；1秒实际值需要十个有效桶。

当前工程用绝对epoch的整秒窗口；t0保持真实首I/O时间不取整。评价只纳入完整落在 t0+180 到 t0+600 区间的整秒窗口，因此真实t0有小数时窗口数可能是419，不能强行补成420。近零筛选前后数量、固定阈值和缺口数均保留。

当前工程的质量策略比单纯计算准确率更严格：评价区间缺桶、漏预测、时钟证据不合格等会使正式轮失败。探索和训练阶段仍可保留这些数据，但质量失败不会被隐藏。

复算结果会输出每个结算窗口、N、实际零值的排除数量、未显示舍入的准确率、4位显示值和错误列表。三轮汇总检查每轮，不以平均值代替。

本工程当前提供采集、处理、训练与日志复算组件。完整在线预测调度、实时特征流和首I/O工具接入尚未部署；不能把离线回放或本地单元测试的时间戳说成现场实时预测证据。
