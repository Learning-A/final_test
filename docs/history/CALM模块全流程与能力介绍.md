# CALM 负载预测模块——全流程与模型能力介绍

> 依据:《04-负载预测模块服务接口规范》《05-负载预测页面接口规范》、仓库全景(c3/models 两仓库建模背景)及测试大纲编写过程中确认的事实。
> 用途:模块整体介绍,可支撑测试大纲"任务书研究内容与评测方法"一节、被测物描述扩写及答辩材料。

## 一、模块定位

CALM(Calibrated Adaptive Load Model,校准式自适应负载模型)是独立部署的负载预测服务,与白泽分布式存储系统解耦:部署于客户端节点,经只读管理接口(admin socket perf dump)观测集群,不修改存储系统任何组件,为存储资源调度与 QoS 决策提供负载提前量。它是指标 1.2"支持 AI 使能的控制面,实现新型计算应用 IO 访问特征动态感知"的核心成果,由四个组件构成数据闭环:**数据采集 → 数据处理 → 模型在线校准微调(预测)→ 预测结果对比**。

## 二、全流程

### 1. 数据采集

- 通道:admin socket 直连 perf dump,只读、非侵入,采集范围覆盖部署清单登记的全部 OSD;
- 采样网格:0.1s(验收冻结口径,支持 0.1/1.0 两档),采样窗口由模块自对齐;
- 产出指标:逐网格的读/写 IOPS、读/写带宽、平均 IO 大小、读写比;
- 采集先于负载启动(预热),检测到负载后进入运行态;
- 另含零集群依赖的本地确定性演练数据源(replay,负载画像逐秒推进 720s),用于联调、演示与接口验证。

### 2. 数据处理

- 网格对齐:形成无重复时间戳、无计数回退、步长一致的连续观测序列;
- 指标聚合:0.1s 网格 → 1s 步长序列 → 10s 窗口均值(预测目标口径);
- 特征构造:滞后、滚动统计、趋势、跨层互引与 OSD 空间特征(详见能力一节);
- 计数器换算:rate=(v_t−v_{t−1})/interval,延迟取 Δsum/Δcount,缺失不补 0。

### 3. 模型在线校准微调与预测

- 冷启动:有效点数不足 warmup(96 点)时以持久性预测并如实标注 cold_persistence,同样计入统计;
- 在线预测:预训练模型逐窗口输出预测,EWMA 在线残差校准持续吸收近期残差、修正后续输出,应对分布漂移;
- 预测口径:变量为 IOPS,步长 1s,预测目标为未来 10 步(10s)的 IOPS 平均值;
- 无泄漏纪律:t+1 时刻只使用 ≤t 的观测,滚动统计一律 shift(1),本轮观测不参与自身模型训练与超参选择;
- 开销:在线预测单窗口参考值约 1.9ms(进程内),不构成采集瓶颈。

### 4. 预测结果对比(结算与终验)

- 结算规则:每个采样窗口闭合时,用上一窗口发出的预测与本窗口实际值结算——先预测、后观测;
- 指标口径:用户负载预测准确度 = 1−WAPE = 1 − Σ|预测值−实际值| ÷ Σ|实际值|(参照 DL/T 1711-2017 负荷预测准确率),达标判定 pass_90:> 0.90;
- 输出:滚动累计准确度(实时)+ 作业终验汇总(accuracy、pass_90、n_eval、insufficient)+ 逐窗口结算记录最终写入日志文件;
- 样本不足(结算窗口 < 2×warmup 或负载时长 < 60s)时如实标注 insufficient,不得下验收结论;采集不可用不以 0 值伪装成功。

### 5. 运行形态(作业生命周期与调用通道)

- 作业状态机:starting → monitoring → running → evaluating → succeeded / failed / cancelled;同一时刻至多一个活动作业;
- 三种模式:replay(本地演练)/ attach(只起采集与在线预测,负载由外部启动)/ monitored(模块一键拉起真实负载,高风险需授权);
- 在线接入:predict/start 仅 running 态有效、幂等,接入后从作业起点连续结算;
- 展示:/forecast 页面经任务接口 + SSE——图 2.1 应用 IO 特征实时感知(读写 IOPS 双线)、图 2.2 用户负载预测准确度(单线 + 90% 验收参考线)、指标条、历史列表与达标徽章;
- 服务接口:GET /health、作业创建/状态/摘要/接入/停止/终验/清理、原始指标游标流(metrics?after=);
- AI 大脑调用通道:以 function calling 工具注册,模型输出调用意图、运行时代为执行;monitored 高风险调用须经调用方授权门。

## 三、模型能力

### 1. 预测对象与时界的设计依据

秒级瞬时值随机性强,"未来 N 秒均值"的可预测性随 N 单调上升(实测 R²:3s 0.452 → 10s 0.711 → 20s 0.821 → 30s 0.847,即"窗口均值现象")。因此预测目标取 10s 窗口均值——在提前量与可预测性之间取得平衡;IOPS 则是资源调度与 QoS 最直接的负载压力量纲。

### 2. 特征体系(两版特征工程迭代)

- 时序侧:滞后特征(lag 1~120s)、滚动统计、差分/对数差分、EWMA、多尺度趋势、相位(sin/cos)——捕捉负载自相关;
- 空间侧:各 OSD 负载份额、排名、z-score、热点分布——捕捉热点迁移与集群拓扑结构;
- 跨层互引:Client/MDS/OSD 三层指标互为上下文(第三代数据 Client 9,222 行 / OSD 110,664 行规模);
- 负载画像:Vdbench 报告解析(rate、MB/s、响应时间、队列深度、CPU);
- 最终特征维度:Client 302 / MDS 274 / OSD 315 列;多步标签 50 万余条(1/5/10/30s)。

### 3. 模型储备(27 家族系统对比)

- 表格基线:last_value、rolling_mean、Ridge、HistGB、XGBoost、LightGBM、ExtraTrees、RF,加 top3/top5 融合;
- 神经模型:循环/卷积(GRU、TCN、TCN-GRU),图/频域(FourierGNN、GAT-GRU),TSLib 18 种(DLinear、PatchTST、iTransformer、TimesNet、FreTS 等)及短序列适配 5 种;
- 统一实验:27 家族 × 77 任务,统一 epochs=200、seq_len=12、seed=2026,验证集选 checkpoint,输出 1/5/10/30s 联合多步;
- 按层按时界择优:OSD 1s 最优 TCN、OSD 5s 最优 GAT-GRU、Client/MDS 1s 最优 FreTS;多数负载场景表格模型 + 在线校准夺冠。

### 4. 在线校准微调(CALM 之 C)

EWMA 在线残差校准(α 0.005~0.1)持续追踪近期预测残差并修正后续输出,是模块应对分布漂移、区分于离线静态模型的核心机制;实测中表格模型 + 在线校准的组合拿下了多个基准最优(第三代 Client 0.953 / OSD 0.904 均为 ExtraTrees + 校准)。

### 5. 实测水平

- 第一代(自建 Ceph,准确率口径 1−MAPE):data_rd/wr 91.62%/91.73%,OSD 总量(5s 平滑)94%+;
- 第三代(五负载基准,R² 口径):Client 0.953、OSD 0.904;分负载 mapreduce 0.933、graphchi 0.906、wrf 0.922;graph 负载 client/osd 0.991/0.990;
- 页面演练锚点:五种负载 93.4%~95.4%;
- 已知能力边界:秒级瞬时值、写路径负载、跨运行泛化是当前弱项——测试采用纯读 SINGLE_workload 与 10s 均值口径,正落在已验证的能力区间内。

### 6. 工程纪律

- 无泄漏三原则:时序切分跨边界标签删除;滚动统计一律 shift(1);本轮观测不参与自身训练与超参选择;
- 数据质检:重复时间戳 0、计数器重置 0、四档步长泄漏 0、每时刻实体数一致;
- 不伪造原则:数据不可用、样本不足如实返回状态与标记,不以 0 值或空数据伪装成功。
