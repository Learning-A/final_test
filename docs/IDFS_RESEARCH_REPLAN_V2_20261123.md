状态：**research_plan_ready / 未执行新实验**。用户本轮要求重新调研和制定计划；本文件不授权自动训练、新现场采集或部署。旧 R1/R2 和原始数据保留，不重做。仅使用现有记录开展的调研、文件核对和交接已在本轮完成；下列实验均为 planned。

## 1. 这次为什么改变推进方式

当前瓶颈至少有三种，必须分开验证：

1. **少量低正值秒造成极大的相对误差。** R2 的 L0 中，105 个不超过 10 IOPS 的正标签贡献节点宏 MAPE 68.26 个百分点。这些是节点标签数，不是 105 次独立停顿。
2. **普通窗口仍有较大误差。** 即使把上述标签的预测事后全部改成真实值，L0 宏 MAPE 仍约为 44.06%。这是固定预测的事后算术分解，不是可实现成绩，也不是不可预测下界。只识别个位数 IOPS 仍不足以达标。
3. **近端信号与线上可获得性尚未同时成立。** R1 仅在 50 ms 源时钟假设下通过研发筛选；100/200 ms 敏感性没有通过。三个已审计 AI 推理低值秒中，两例明显下降晚于输入截止，一例源端提前下降；没有推理端接收证据和跨机时钟误差界。

因此主线改为：**完整轮次的误差和信号地图 → 原始字段的时间安全处理 → 普通窗口偏差/跨负载迁移 → 有证据的短时结构 → 有前兆时才研究低状态决策 → 跨轮复核与冻结**。不再把“有下一阶段”理解为必须进入更多专家或更大网络。

| 已完成 | 核实结果 | 对新计划的约束 |
| --- | --- | --- |
| R1，固定树增加近端 100 ms 输入 | 节点宏 MAPE 119.09%→108.07%，相对改善 9.26%；0/40 达标 | 保留为匹配基线；更保守余量不稳健，不能宣布在线可用 |
| 冻结森林数组执行 | 同一批预测完全一致；离线特征+推理 P95 50.12→5.03 ms | 复用加速实现；不重跑相同基准，不把它计作精度提升 |
| R2，固定小 MLP 四损失 | L0/L1/L2/L3 宏 MAPE 112.32/101.74/107.75/94.01%；均无晋级 | L3 的 MAE 退化保留；不重复扫 Huber、权重或阈值 |
| 早期状态模型 | 命中 4/38，误报 98；软修正整体压低预测 | 新状态方案必须超过常数收缩，不能直接混合未校准概率 |
| 三个 AI 推理低秒原始审计 | 16 客户端、96 OSS 差分完整；目标合计 35/14/10 IOPS | 不删除正值；仅 client7414 在邻域有正调用，其余恒零不是前兆 |

## 2. 指标、样本和证据边界

正式目标继续是下一完整秒 [S,S+1) 内，八节点各自 12 OSS 的完成操作总数/秒。正式 MAPE 只排实际零值；准确率=100×(1−MAPE)，严格超过 90% 即 MAPE<10%。不改分母、不设评分 floor、不截断负准确率，不以集群总量代替节点成绩。

研发主表是五类×八节点 40 组等权宏 MAPE；另列最差组、每负载节点宏 MAE、WAPE、偏差、覆盖、真实零预测误报。读写头相加、全局量/份额头等都最终形成相同节点 total 标签。真实零仍进训练及 MAE，不能从数据中删掉。

数据固定为原 15 train，默认仍 10 轮 train01/02 拟合、5 轮 train03 内部开发，原 5,328/2,661 秒共同键作为主对照。五个外部 development-validation 早已被查看一次，本轮不读取或再评分；正式独立轮仍未执行。旧故障轮不混入主训练，若以后作鲁棒性研究必须另卡。

新字段不能靠删除缺失/难预测样本提高成绩。主对照保持原共同键；扩大历史覆盖另列 full-coverage 表，不替换主表。某字段在某轮缺失时用 mask/age 表示，不补作真实零、不双向插值。

**研发筛选预设**：相对同卡匹配基线宏 MAPE 改善≥5%，最差组相对退化≤5%，五类各自节点宏 MAE 相对退化≤5%；全窗口覆盖不下降。另列低值与普通窗口结果，普通窗口阈值 100 IOPS 仅用于延续 R2 诊断，不影响评分或在线门控。未达门槛保留取舍，不自动调低标准。

## 3. 数据处理：先补语义和时效，再增加维度

### 3.1 全轮误差与事件地图，A 主责，B 复用冻结预测

覆盖全部 15 train 的已有标签/计数；模型误差仅使用相应已有冻结预测，不把拟合内误差当泛化成绩。按 run、节点、负载、真实量级、下跌/恢复/平台、输入缺失/age 统计；报告事件段数、长度、幅度和源时钟同步范围。事件按连续窗口合并后计数，八节点同一扰动不当八次独立事件。

需要回答：普通窗口是持续偏高、节点份额偏差、读写转换误差，还是短时随机波动？训练轮与 train03 的量级/读写比/缺失率有多大变化？低值之外的 44.06 个百分点分别来自何处？现有特征的最后有效观测与目标相隔多久？

前兆研究必须扫描完整轮次的所有预测时刻，并包含无事件时段。固定查看历史 0.1/0.3/0.5/1/2 秒的可用计数、变化、零游程、活跃实体、age/coverage；状态诊断沿历史已登记定义，不据 train03 调阈值。真实未来状态只作辅助标签或事后分层，不能当特征。

先列频数和时序图，不以检索“形状相似的已知坏点”选择模型。若尝试简单规则，参数只从拟合轮确定，在内部开发报告漏报、误报/分钟、首次预警提前量及全窗口回归损失。事后选出的三个窗口不能估计总体召回。

### 3.2 三套时间，不把未知写成零延迟

每条输入记录保留：事件桶区间、源读取结束、采集端收到、推理端收到（如有）、时钟域/误差界、单位、实体/boot/instance、有效性和来源哈希。

主研究仍用截止 D=S−30 ms、额外源时间余量 50 ms：桶结束和源可用上界均须≤S−80 ms。100/200 ms 沿既有敏感性，仅对冻结少量候选作明确记账的离线评估，不能事后换主档。把桶界挪到 S 后或用结束于 S 的桶预测 [S,S+1) 会泄漏。

工作站接收戳与源戳表面相差约 17 秒，当前不能区分时钟差和传输/缓冲，不据此减去常数“校正”。同一时钟域的接收间隔可诊断批量到达，不能推出跨主机单向延迟。若旧记录无法给出时钟界和推理端到达，所有新模型继续标记 offline_source_clock_only；这不阻止离线比较，但阻止在线资格声明。

### 3.3 有限的三组输入

| 输入组 | 处理方法 | 必须通过的检查 |
| --- | --- | --- |
| C：已核验 core | 复用 R1/R2 的 F0+F1，带真实 mask/age；保留读写、短5秒/长15秒、空间信息 | 字段顺序、原秒标签、5,328/2,661 样本和截止规则逐项复现 |
| B：字节与请求结构 | 原始累计 read/write bytes 先按相邻有效样本差分；分别聚合 bytes、ops，再用 sum(bytes)/sum(ops) 作代理大小 | 计数同源/同间隔/身份不变、无回退；ops=0 时比例缺失；客户端 RPC 与 OSS 完成量不互换 |
| P：服务压力和客户端活动 | op_wip 为瞬时 gauge；历史区间 last/max/均值及 age。latency 若确认为累计 count/sum，则差分 sum/差分 count 后求均值。客户端逐实体完整性/活动再汇总 | 缺字段仍缺失；延迟累计语义和单位先核对；不差分 avgtime，不把全程 maxtime 当桶 p95；16 路不无条件求同语义总量 |

只从现有 raw 导出，不在本轮联系集群补数据。R1 core 主要包含节点计数与 client7414；新包应先审查所有 16 路来源/挂载/重复性，再决定哪些作为独立活动证据。静默的 15 路只能作为覆盖证据，不能冒称有效的业务先行量。

5 秒系统遥测仅作后备组 T，不并入第一批。先检查各轮缺失与 host 映射，再按截止前 as-of join，附 age/TTL 和 mask。TTL 拟固定为 10 秒，另报告覆盖，不向未来/上一轮借值。AI train03 缺失和 AI inference train03 部分缺失保留。只有 core+B/P 已有跨轮增益时才用 T 替换未执行分支；防止通过缺失模式识别 run。

所有聚合都按 run 重置。真实观测零参与归一化，缺失占位不参与；训练中心/尺度仅在拟合轮计算。bytes/latency/op_wip 的正式字段名、采样语义、单位和有效谓词须在执行卡冻结，不能直接运行本表。

## 4. 模型路线：优先解决普通窗口偏差

### 4.1 不学习的基准与新输入对照

用现有留出预测重算 last-valid、历史短窗中位数和零预测等基准时，记录为新增诊断；如旧结果完全相同直接复用。按截止可见曝光形成统计，不把部分 100 ms 桶无说明放大为整秒。零预测对每个正标签的 APE 恒为100%，可检查模型是否连这一退化基准都未超越，不能以它作为生产策略。

输入先用同一 ExtraTrees（64树/depth8/leaf3/seed2026）做 C、C+B、C+B+P 的三臂，模型损失不变。每臂8个节点回归器，集群只求和，不新增第九个拟合。C 与旧 R1 完全相同时复用；任何字段顺序/样本/实现不一致都必须登记新匹配基线。先完成字段贡献判断，再决定网络输入。

若 B/P 不改善，不继续堆这些维度。若当前字段根本没有低事件前兆，停止该事件路线，仍可继续普通窗口和跨负载偏差路线。

### 4.2 共享模型、历史局部尺度与负载分工

网络比较固定训练 loss=L0 缩放 MAE，沿用 R2 的优化器和 checkpoint 规则；本轮不继续搜索 L1/L2/L3 权重。训练拟合尺度保持原定义；局部尺度只来自截止前输入，不能读本轮全程统计。

四个有明确差异的候选按顺序登记：

1. **M0 共享 MLP 匹配基线**：沿用 2×64、node embedding4、小模型规格；输入改变就登记新基线，完全相同则复用 R2 L0。
2. **M1 历史局部尺度/残差**：相同主体，在历史已观测窗口计算局部量级及有效覆盖，把量级/波动作为独立输入并恢复到原 IOPS；预测历史基线的非负修正。它与标准 RevIN 有 mask、单位和非负输出差异，称为受其启发的适配，不能宣称原版复现。对零历史/近常数序列有训练固定的最小尺度和 fallback。只固定一个版本，不扫窗口长度。
3. **M2 已知负载的小适配头**：在 M0/M1 中按预设筛选胜出的同一骨干上，增加五个轻量 workload adapter；保留共享输出与 unknown-workload fallback。训练清单里的业务类型只能在真实预测前有同类元数据时使用；否则该臂是条件研究候选，不能宣布普遍部署。与不加 adapter 的匹配骨干比较，不同时更换损失和时间窗。
4. **M3 短因果 TCN**：保持已选定的尺度/adapter/输入与损失，仅将短100ms支路替换为 channels32、kernel3、dilation1/2/4 的因果卷积，接同样历史摘要。公开感受野、mask处理、参数量和CPU耗时；参数目标≤20万，并尽量接近匹配骨干。

M1 只有同一输入/损失下的比较能归因尺度处理；M2 才检验负载间负迁移，不能用当前每类一轮的最好结果拼接。M3 才检验顺序信息，不能因 MoE 名称更复杂就跳过这些对照。

读写双头、全局总量×节点份额（softmax份额确保节点求和一致）、多组 MoE 均是**替换分支**，不默认追加。根据全轮误差地图分别在读写切换、份额迁移、至少两个有效输入组有互补贡献时，替换尚未执行的一个结构卡。读写标签完整性单独核验；全局头仅辅助，不用集群高分替代节点验收；MoE 必须有同专家集合的均匀融合、容量和移除诊断。替换前发布修订，保持总预算不增。

### 4.3 低状态与分布决策：有进入条件的后备路线

仅当全轮前兆研究显示截止前信号，且训练中有足够独立事件段覆盖，才建立“活动/低状态+条件幅度”模型。先比较训练内常数收缩、固定回归器、动态修正；常数参数和概率校准只能用拟合轮内部按完整轮生成的 out-of-fold 预测，不能在 train03 调优。

概率报告 AP、PR、Brier、可靠性、误报/分钟、首次提前量；balanced 分类分数不是可靠发生概率。若训练内独立校准分区没有两类覆盖，跳过概率校准，不能借外部开发数据补齐。极少数事件不适合灵活 isotonic。

如果选择条件分布路线，先固定一套低参数分布/分位数表示，与相同输入的点回归对照。**混合分布均值通常不是 MAPE 的最优点预测。** 对正 Y，MAPE 的最优点为按 1/Y 加权的条件中位数；须写出推导/数值决策与下界处理，真实零对正式 MAPE 的排除单独处理。分布输出用覆盖/校准评分检验，最终节点点预测仍按原正式口径评价；不能只因预测区间更好就称准确率达标。

TSB/Croston 的间歇需求思想用于“发生概率与幅度分开”这一备选机制；当前多数时间高活跃、偶发同步瞬停，与库存需求大量零的任务不同，不直接套用其平均需求预测，不以论文库存指标作为本项目证据。

### 4.4 五类负载的不同优先级

负载原生版本保持 `ChrisLzt/idfs-workloads@fb83711a1226f59899ed034b9195402156ef57d6`。静态池审计提示 Baleen 当前 EC8+2、其余当前三副本；历史逐轮布局未知，不能硬乘比例修标签。

| 负载 | 优先检验 | 不采用的未经证实先验 |
| --- | --- | --- |
| AI训练SES | bytes/ops代理大小、读写结构、平台偏差和负载适配头 | 不发明epoch/checkpoint周期；70/30请求比不当OSS完成比 |

## 5. 跨轮评估与选择历史

第一轮开发仍用 train01/02→train03，便于与 R1/R2 比较；train03 已被大量使用，不当全新证据。候选仅保留最多两个，随后做各负载同 index 留一轮的另外两折（heldout01、heldout02），所有尺度、归一化和校准在各折重新拟合。

该三折是**现有训练角色数据上的组留出稳健性诊断**：每折训练可能含较晚采集的其他轮，不代表按时间外推，也不是新的未见测试。每折内仍严格按 cutoff 形成特征，不跨 run 搬历史。若要做时间外推，单列 train01→train02 与 train01/02→train03 的预登记对照，不能混为同一种CV；它替换未执行稳健性卡，不额外扩张。

checkpoint 默认仍各折开发宏 MAPE 选取并记账，因此这些折仍参与选择。少数最终候选做固定 epoch 的补充复核时，epoch 只从内层拟合分区确定；不能一边看外折最好 epoch 一边称外折未参与选模。每折输出都保留，不只展示最好折。

跨轮筛选补充要求：三折宏平均相对匹配基线改善≥5%，至少两折改善，任一折宏 MAPE 相对退化不超过5%；逐负载 MAE 与最差组约束继续列出，失败不得按总体平均掩盖。只有三轮/负载，不用窗口 bootstrap 或八节点数制造狭窄显著性区间。跨轮结果只作研发证据，正式结论仍需未来另行授权的独立轮。

## 6. 分阶段卡与计算上限

## 9. 如果仍不达标，分别交付什么

- 新字段无贡献：交付信息时效与贡献否定结果，保留core轻模型，不扩维。
- 普通窗口改善、瞬停仍差：分别列可控偏差和缺少先行信号的事件范围；不能称整个任务不可预测。
- 状态MAPE改善但MAE恶化：保留Pareto取舍，拒绝靠整体压低预测晋级。
- 跨轮不稳健：报告哪类负载/节点/阶段失效，不挑轮拼通过。
- 时间证据缺失：允许冻结离线候选，列未来所需源/接收双时间戳与时钟界；不启动采集、不宣称上线。
- 现有记录不足以支持下一假设：形成下一次采集的最小证据清单，另行决定现场窗口。不会承诺扩大模型就必然超过90%。
