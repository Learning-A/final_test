# V2-M2 轻量负载适配头

2026-11-23。待登记。M1 的相对改善低于 5%，本卡沿用 R2 L0 的原共享骨干及冻结预测。检验录制清单所载负载类型是否能改善同一批预测，尤其是已在 D0 发现的普通阶段误差。五类均采用相同规则，所有有效秒都进入比较。

使用原 258 维 C、原 5,328/2,661 秒及八节点。冻结预处理、目标尺度、run 和节点权重、批次顺序、L0 缩放 MAE、seed2026、AdamW、batch128、梯度裁剪 5、上限 60 epoch 和 patience8 均沿 R2 L0。以 40 组宏 MAPE 保留最佳 epoch，含 epoch0，同分留早。预测截止仍为源时钟 S−80 ms 假设。

取原共享骨干末层前的 64 维向量。每个已知负载有一个独立线性头，将标量修正加到共享输出的 softplus 之前，最终乘原节点尺度。五个头的权重和偏置全为零初始化，epoch0 与原共享预测一致。固定类别顺序为 AI 推理、AI 训练、Baleen、Graph、WRF。未知负载使用恒零修正，走联合训练得到的共享输出。原 21,089 个参数加 325 个，共 21,414 个。性能差异归于带负载标签的小头整体变化。线上使用需要另有证据证明负载标签在预测前可得。
