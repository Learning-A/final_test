# IDFS 两端实验汇总与效果解释

更新：2026-11-23，北京时间。A 负责原始数据、时间语义和独立复核，B 负责特征、模型和有界训练；早期诊断 pilot 由 A 执行。旧实验直接复用，新授权 T0–T3 已另卡执行；下面将新结果单列。

## 结论与比较口径

目前没有正式达到八节点各自下一秒 IOPS 准确率严格超过 90% 的证据。原口径仍为 accuracy=100−MAPE，仅排除真实零，所有低正值保留；内部筛选的 5% 相对改善门槛不等于正式达标。后续可以研究更合适的指标，但用户允许调整指标不表示已经选定新验收公式。

已有最明确的精度收益来自近端 100 ms 信息：同一轮次划分和固定树下，50 ms 源时钟假设的节点宏 MAPE 从 119.0908% 降到 108.0662%，相对改善 9.26%。100/200 ms 两档不稳健。最明确的工程收益来自冻结数组推理：同样本、同预测，离线组件 P95 从 50.122 ms 降到 5.029 ms。两者都尚未证明实际服务接收、跨机时钟界和现场发布。

以下分区不能混成一条优化曲线：故障单轮 pilot 为每目标 271/125 秒；五负载首轮树为 1215/697 秒同轮切分，MoE 扩至 1514/762 秒；独立开发轮冻结评估为 2400 秒；当前主系列是 train01/02 共 5328 秒拟合、train03 共 2661 秒内部开发，源角色均为 train。早期宏指标常包含五负载×九目标，当前主指标是五负载×八节点，集群另列。

## 4. 为什么有些方法有用，有些没有用

**较有把握的解释来自匹配实验和原始记录。** 近端信息比旧秒级历史更新，R1增益确实随可用桶减少而减弱；这支持近端信息有增量，但没有隔离每一类桶的独立贡献。冻结数组的速度收益来自执行表示改变，预测精确相同，因此不是精度换速度。M2的改进与业务条件化一致，但单seed、类型可用性和跨轮稳定性尚未充分验证。

**低正值放大MAPE有直接算术证据。** L0中1–10 IOPS仅占正标签约0.49%，贡献约68.26个宏MAPE百分点。一个实际1、预测100的点就是9900% APE。低值并非缺失补零，可保留其它辅助指标讨论用途，但不能删低值后宣称原指标提高。

**部分“好分数”源于误差重新分配。** L3下降首秒贡献79.04→60.90点，ordinary仅32.83→32.60点，五负载偏差均转负、MAE上升。软状态修正也整体压低预测。两者支持“用普通窗口低估换取低值相对误差下降”，没有证明学会了可靠事件先兆。

**输入信息和事件时序限制仍在。** A核查的三个AI推理事件中两例下降晚于假设输入截止；简单探针误报多。bytes/压力在当前编码和固定树上未补上这类信号。以上没有证明所有瞬停不可预测；GC、缓存、调度、物理放置等具体原因没有足够现场证据，不能写成已确认根因。

**总体均值相似不代表秒级轨迹可重复。** 四轮原生配置和model SHA一致，而max-rate完成量受实际运行时序影响，AI/Graph的同偏移一秒相关很弱。WRF粗阶段更可重复，但阶段起点还没认证。增加模型容量或记住某轮时间曲线不能自动解决跨轮差异。

**更复杂模型并未产生稳定收益。** 早期MoE只有内部小幅收益，独立轮没有明显优于GRU；TCN本次更差，负载适配头较一致但幅度小。不能从一次结果确定容量、损失、优化或信号不足各占多少，也不能凭测试全绿推出模型准确率达标。

## 5. 对数处理、当前新实验与未做事项

已经做过：早期树的对数目标、早期GRU的训练内log输入归一、R2训练内观测标准化、R2原输出上的log-Huber、M1局部尺度/残差、冻结输出的辅助指标敏感性。它们不等于当前C258同容量下log输入+robust及显式log目标的完整对照。

A对R2冻结预测增加辅助评分：L2的logMAE0.28310、宏RMSLE0.61149、WAPE21.6178%，均与原MAPE107.7508%并列。按MAPE是L3最好，按logMAE/WAPE是L2，按宏RMSLE是L1。用100−log域MAPE得到约93–94不代表原IOPS任务达到90%准确率。

新授权T0复用R2 L0，T1固定178个非负连续列log1p+训练median/IQR、3个signed差分仅robust、77个mask/fraction/age保持；T2固定T1输入，采用显式log目标、MAE和expm1恢复。两臂已在b507各拟合一次，完整租约约21.30/22.54秒。T3训练诊断0列满足预登记条件，低于18列准入门槛，未拟合。

T1宏MAPE112.1806%，相对T0仅改善0.12%，五类MAE均恶化；T2为105.9579%，相对改善5.66%，但AI训练MAE增加8.40%，超5%限额。两臂均未晋级，0/40节点组通过。T2宏RMSLE0.60949比T0的0.61613好，但logMAE0.29394和WAPE22.9231%比T0的0.28529和22.1503%差，不能只挑其中一个数声称全面改善。B已另写代码复算，A也独立核对原标签、指标、上下文及最终ZIP全部26成员一致，本轮已结案。 [本轮实际结果](B19_DATA_TRANSFORM_RESULTS.md)

截至本文，尚未完成正式独立轮、线上实际服务接收/发布验证、逐轮有界跨机时钟、晋级候选三折与多seed复核、可靠OOF校准或可验证物理暂停根因。这些缺口不能用已有工作流、模型数量或辅助评分替代。
