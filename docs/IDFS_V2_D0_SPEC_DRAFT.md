## 2. 样本和时间谓词

S为下一秒目标起点，目标区间 `[S,S+1s)`，发布截止 `S−30ms`。源时钟离线主假设额外余量50ms，因此所有输入桶 end 与 `max(end, source_available)` 须≤`S−80ms`。主时间轴为整数纳秒，不用浮点秒寻找事件。

目标节点需12 OSS、10个100ms桶完整；集群诊断需八个目标节点完整。不能把不完整目标补零。每个输入桶保留实体、boot/instance、单位、采样有效性、源可用时间、收到时间及其时钟域；禁止跨run历史、居中平滑、目标同秒客户端输入和事后日志输入。

时间界未知时仍可做源时钟假设诊断，但所有结果标记 `offline_source_clock_only=true`、`online_time_eligibility=false`。没有推理端收到时间不得用工作站接收戳替代；不得从约17秒的表面差中拟合一个“同步修正”。

## 3. 事件与连续段

以下是本卡预设诊断定义，不替代正式评分。分类用未来目标作标签，特征不能读取它。

1. 节点量级：零、`0<y≤10`、`10<y≤100`、`100<y≤1000`、`y>1000`，与R2既有分层一致。
2. 集群低状态：令L(S)为截至`S−80ms`已可见、在`[S−5s,S)`内结束的最近完整一秒集群操作量；Y(S)为目标秒八节点总量。定义 `quiet = Y(S)≤max(10,0.1*L(S))`。L缺失时状态标签unknown，不能当正常或低状态。0.1、10是本卡预设诊断阈值，不在train03调优。
3. 在相同run将连续整数秒quiet合并为一个事件段；跨缺失目标、unknown状态或时间gap必须断段。节点低值另记run+node连续段，再按有重叠目标秒的节点段合并为共同扰动描述，不当八次独立事件。
4. quiet段首S仅在紧邻前一秒S−1s有已知非quiet标签时，标记为可确认下降首秒；前一秒缺失、unknown或超出范围则标left_censored，保留低状态秒但不算已确认下降。L=0时仍可定义quiet，也必须遵守此规则。
5. 段尾后的紧邻一秒有已知非quiet标签时，该秒才是恢复；紧邻下一秒缺失、unknown或超出范围则right_censored，不跨空档认定后续恢复。
6. 每个S的阶段标签互斥：known_onset、quiet_left_censored_start、quiet_continuation、known_recovery、ordinary或unknown。另用独立布尔标记前后2秒邻域，不将邻域混作互斥阶段。目标后记录只作诊断标注，永不进入输入。

D0须列各类定义的事件数、长度、跨节点范围和每run暴露秒数；不得只交付误差最大的若干窗口。连续段合并只用于诊断，正式MAPE仍逐原始正标签评分。

## 4. 固定先兆探针，不调分类器

先检查两个预设历史规则，作为可检验的描述性探针，不拟合分类器，也不从train03寻找最佳阈值。

- **P-OSS**：固定最近名义槽结束为 `E=floor((S−80ms)/100ms)*100ms=S−100ms`，取该槽完整集群100ms计数v。该槽缺失、不完整或晚于截止即不发提示；不回退到旧槽，避免停采后复用陈旧末桶。参考槽固定为结束于E−100ms…E−900ms的九个名义相邻槽，其中至少六个完整且可见，取有效参考槽计数中位数m。不能替换成最近九个观测值。仅当m>0且`v≤0.1*m`时发出低活动提示。
- **P-client**：同样规则用于client7414的READ+WRITE计数；不足覆盖或m=0时不发提示，并记录原因。其余15路先审查独立性和历史正调用覆盖，不能作为16票多数表决。

两个探针分别报告，不按内部开发结果挑一个合并为“最优系统”。这些阈值是预设对照，不是已经验证的检测器。若后续要改窗口、阈值、客户端聚合或规则组合，须在新卡中只使用拟合轮选择，并保留选择次数。

每个目标S只用D前数据做一次提示，目标后的反应不算提前命中。提示可用时间上界为所有参与桶的 `max(bucket_end, source_available)` 的最大值；提前量=`S−该上界`，只能称源时钟提前量。无法确认跨域对齐时不比较客户端与OSS物理先后。每行写入v的E、参考槽列表、有效性、age和不可用原因；本卡不允许v回退，过期/缺槽单列。

## 5. 召回、误报和缺失分母

分别计算：

- 秒级quiet召回：命中的quiet秒/有确定quiet标签的秒，缺失输入不发提示并计入漏报；同时公开可观测子集成绩，不以其替代全分母。
- 事件段首秒召回：可确认下降首秒S之前合规提示数/有已知非quiet紧邻前一秒的可确认下降事件段数。left_censored段不进入该分母，另列所有quiet段数、截断数及首秒可评覆盖；段中才提示不能当提前预警成功。分母0写null。
- 精确率：目标为quiet的提示秒/目标状态已知的提示秒；unknown状态提示不算误报，另列alert_unknown_label和所有提示总数，不把它悄悄当负类。不把预测正确的幅度与分类命中混为一谈。分母0写null。
- 误报/分钟：非quiet目标秒的提示数/`(有确定非quiet标签的秒数/60)`。分母为0时记null。另列连续提示合并后的误报段/分钟，避免持续提示被误解为独立事件。
- 可观测覆盖：满足探针前置条件的秒/有确定状态标签的秒；并列unknown状态、无历史、缺桶及m=0的计数。缺失不是正常。

按run/负载、下降首秒/持续低态/恢复、源时钟提前量分层，报告原始整数计数。不依据这些探针事后修改冻结回归输出；D0仅诊断，不增加正式模型评分或宣称检测收益转化为预测收益。
