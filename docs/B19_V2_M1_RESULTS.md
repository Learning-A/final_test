# V2-M1 历史尺度与残差对照结果

M1 的内部开发节点宏 MAPE 为 111.4146%，原 R2 L0 为 112.3163%。相对改善 0.8029%，低于预登记的 5% 门槛，保留 R2 L0 作为匹配基线。两臂均为 0/40 组达到 MAPE<10%。参见 [执行登记](https://github.com/Learning-A/final_test/issues/19#issuecomment-7090948805)。

| --- | ---: | ---: |
| 节点宏 MAPE | 112.3163% | 111.4146% |
| 最差组 MAPE | 341.4612% | 341.8063% |
| 下降首秒贡献 | 79.0361 个百分点 | 78.4542 个百分点 |
| 普通阶段贡献 | 32.8268 个百分点 | 32.5198 个百分点 |

普通阶段的平均节点 MAE 在 AI 训练、AI 推理和 WRF 上有所上升，在 Baleen 和 Graph 上有所下降。最佳检查点为第 12 轮，共训练 20 轮，含第 0 轮共 21 次内部评分。最佳检查点在 22 个正标签上预测为零。该数字描述输出截为零的结果，无法单凭它确定训练期间梯度受限对得分的影响。

新作业在 B 的专属 GPU 上拟合一次，共用原 5,328/2,661 秒、原 R2 预处理、批次顺序及 L0 损失。worker 用时 27.026 秒，资源租约 29.101 秒。复核覆盖 2,661 秒、21,288 个原节点标签、80 组指标及 D0 阶段贡献，新增外部验证评估为零。A 已独立复核一致。另见 [训练报告](../reports/v2_m1_local_residual.json)、[B 的独立复算](../reports/v2_m1_result_verification.json) 和 [A复核](https://github.com/Learning-A/final_test/blob/c056bc8/reports/v2_m1_A_independent_review.json)。
