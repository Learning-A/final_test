# 带缺失掩码的多尺度输入准备

schema `masked_host_multiscale_v1`，144维，替代候选输入而非直接兼容原82/432维权重。没有训练新模型或改变正式目标。由`idfs_lab.masked_inputs.build_masked_input`产生：

- short [0,35)：严格完整且及时的自身5秒读/写/总量、统计、差分、读占比。
- long [35,112)：15个历史lag各三数值加一个observed mask，共60维；仅对已观测值计算15个统计，另加覆盖率与最旧实际历史年龄。
- spatial [112,144)：八节点最新可用读/写/总量与观测mask。

最新输入秒仍从目标前2秒开始，结算截至目标前1秒，所有被消费值必须在目标前30ms可用。history_start_ns明确本分区历史下限，之前长历史直接mask，不跨train/development/run。短历史缺失或迟到拒绝该输入；可选长历史缺失/迟到只用明确配mask的张量占位，统计不把这些占位视为真实零。真实零的mask=1。目标标签完整性在数据集层保持不变，不能补零/插值。

只读审计`scripts/audit_masked_coverage.py`在原15秒可评估时间轴上核验五包全部文件哈希，要求完整八节点标签，产生reports/masked_input_coverage_v1.json：训练1514、开发762，共2276秒，与先前5秒历史覆盖一致，比原严格15秒1912秒多364秒。该结果只是输入可用性，没有新准确率结果。将来模型比较必须同时报告旧1912秒共同交集和各自完整覆盖，禁止通过换样本来解释提升。

4项新边界测试检查缺失与真实零、可选迟到与短历史拒绝、分区/未来值不可影响输入、已观测非有限值报错；全套93项通过。Windows无拟合。源available仍只有read-end证据，未认证在线接收或跨机时钟同步。
