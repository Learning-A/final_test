# 集群1/3/5/10秒：直接整秒与100ms多步路径对照卡

## 任务定义

在同一个历史截止S−80ms，一次预测[S,S+10s)的全部未来量，所有未来标签只参与训练/评分，不作为输入，不逐步喂入未来真实值，也不以到达新历史后的滚动预测冒充同一时刻的10秒预测。

共同输出有：未来10个完整秒的IOPS轨迹q1..q10，及未来1/3/5/10秒窗口平均IOPS，即mean(q1..qH)。未来窗口总操作数=H×平均IOPS，另存用于单位核对。窗口平均与第H秒IOPS是不同指标，分别报告。

两条新路线：

- direct_seconds：一次预测10个未来整秒IOPS，再聚合1/3/5/10秒窗口均值。
- fine100ms：一次预测100个未来100ms桶的IOPS速率（对应原操作数×10），每十步取平均还原逐秒IOPS，再聚合相同窗口。其前10步聚合正是用户要求的“预测10个100ms后算1秒”。

这是一组多期限共享模型对照，不是分别为每期限追加一个最优模型。direct_seconds也是多任务10秒轨迹，其1秒头与原先单1秒任务不同，不能称重跑旧模型。两条路线是直接多输出，不是递归单步模型；本卡不追加递归或其它骨干。

## 同容量与训练规则

两臂参数完全相同、初始化相同。encoder1840→64→64；共享decoder输入64维latent与2个固定时间坐标（区间中点/10、区间宽秒数），66→32→1，ReLU、输出softplus。direct用10个宽1秒的坐标，fine用100个宽0.1秒的坐标。共享decoder参数量相同，不因输出100个桶而扩容；这是假设一致的有界pilot，不能代表所有多步网络的能力上限。

输出=训练集群尺度s×softplus(h)，s仅b507内根据本卡拟合起点第一秒正标签中位数估计、下限1；两臂相同数据，因此s应精确一致。最后层零权重、bias=log(expm1(1))，epoch0为s。训练原尺度缩放MAE，逐native目标平均、10个训练run等权（每run .1），无未来量条件加权。目标尺度拟合计入资源租约。

固定seed2026、batch128、AdamW lr.001/decay.0001、clip5、最多40epoch、patience6。相同训练run、batch排列和初始参数hash应一致。checkpoint按五负载×四窗口WAPE等权平均选择，同分保留早轮，包括epoch0。该选模指标明确区别此前节点MAPE，不把结果宣称同旧选模协议提升。

每臂最多1800秒全卡，同一纯数据准备保守预留300秒，worker硬限1500秒；两臂总上限3600秒。首段纯准备实测42.27秒，追加全未来秒标签核验后，原60秒记账断言中止而未保存追加计时；该过程没有模型拟合。启动前保留此记录并扩大准备预留到300、缩短worker，完整卡上限不变。不能用剩余时间扩配置、重跑或改窗口。
