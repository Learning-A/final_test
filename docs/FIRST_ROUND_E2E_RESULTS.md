## 已定位问题与下一实验

1. AI推理集群实际值最低约10%（14/147秒）贡献93.82%总APE，最小实际值12 IOPS。它是误差集中现象，不足以断言负载阶段或采集错误；需A补核负载边界/时钟证据，并核对零/低负载、突变与到达时间。所有低正值继续计入正式MAPE。
2. 15秒连续完整历史与八节点共同交集导致大量窗口拒绝；应做按原因/位置分解及因果mask输入对照，缺失标签不补零，不能仅缩小难样本来改善分数。
3. 下一有界实验优先固定此数据划分比较自身历史/读写/空间输入，以及原尺度、log、相对误差/鲁棒组合损失。多MoE应比较短长时/节点内与跨节点专家，记录门控和专家塌缩；暂未宣称已经训练。避免先按各负载开发结果逐类挑最好模型后宣称统一方案达标。
4. 当前候选均不冻结。需更多独立开发轮检验阶段和低负载泛化，完成CPU可部署导出/整体时延，再由A现场验证正式口径。
