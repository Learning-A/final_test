# R2 固定输入与骨干的损失对照草案

状态：design_only_not_running。此文细化原 14 节计划中的 R2，不创建作业、不拟合预处理、不运行模型评分。R1 拟合及冻结森林执行卡均已完成，禁止重做。新导出执行版本仍待 A 独立对拍；实际 R2 须另固定实现、代码与配置哈希、数据/样本/schema、唯一 job_id 和总预算后才能执行。

## 要回答的问题

在同一轻量骨干、完全相同的源时钟离线输入上，MAE、Huber、log-Huber 和固定组合损失如何改变低值与常态误差？本卡只解释四种损失在同一骨干上的差异。原 R1 树作为背景参考；树与神经网络之间的差异同时包含模型因素，不能单归因于损失。

输入固定为已登记的 F0+F1 节点 258 维、50 ms 源时间假设；8 节点各 12 OSS 的下一秒总 IOPS。15 轮原 train 按 10 个 train01/02 拟合、5 个 train03 内部开发，沿用全部 5328/2661 个共同秒键，保持原 source_role=train。缺失仍用原 mask，标签不补零、不插值，不增添压力、客户端细粒度、阶段真值或长60分支。100/200 ms 结果保留为已有失败敏感性，不选另一档救分。

## 同一骨干与训练内状态

拟议采用共享节点 MLP：258 维输入加 4 维节点 embedding，两层各 64 单元，逐节点非负输出。八节点共享主体，保留节点身份；本卡不建立直接集群头，集群仅报告节点求和，cluster loss 为 0。没有门控、状态头、校准或逐负载选择。

全部训练内状态只在 b507 的拟合轮计算。特征中心/尺度、掩码字段处理、目标尺度及节点顺序在实现前列出实际字段表和哈希；当前不计算这些统计。mask 保持语义，不能对缺失值作无标记插补。连续特征归一化只用训练观测值，缺失占位在变换后恢复为对应占位并保留 mask。若无法从已固定 schema 确定观测/掩码关系，先停止预处理设计，不把所有零当观测值拟合统计。

258 维输入契约和训练统计入口已实现。七项合成功能检查通过，包含字段名称、真实观测零与缺失占位的区分，以及错误主机或数据角色的拒绝。共享 ReLU MLP 与四个损失仍待接入。字段说明见 [输入尺度规格](B19_R2_INPUT_SCALING_SPEC.md)。

各节点输出尺度 s=max(1,拟合轮正标签中位数)，相对项下限 τ=max(1,拟合轮正标签第10百分位)，具体分位数算法需在代码中固定。无正标签的节点停止本卡，不从内部开发轮补尺度。网络输出按 s 缩放为 IOPS；相同初始化和 epoch0 输出须在四臂间逐项相同，并保存输出变换定义。

## 原计划四臂

令 a=(预测−实际)/s，z=log(1+预测)−log(1+实际)，r=(预测−实际)/max(实际,τ)，Hδ 为原计划的 Huber。输出非负，训练真实零保留；正式 MAPE 只排实际零，评分不使用 τ。

| 臂 | 固定训练目标 |
| --- | --- |
| L0 | mean abs(a) |
| L1 | mean H1(a) |
| L2 | mean H0.1(z) |
| L3 | 0.5 mean H0.1(z)+0.25 mean H1(a)+0.25 mean H1(r) |

所有臂采用相同按负载和完整拟合轮等权的样本权重，节点等权，不对低状态过采样。实现需验证每轮与每类的总权重；不能把样本复制数当独立数据。固定 seed2026、AdamW lr0.001/weight_decay0.0001、batch128、梯度 norm5，最多60epoch、patience8；精确 batch 顺序和初始化共同冻结。四臂均按相同 train03 的40个节点×负载组宏 MAPE 选择 checkpoint，保留 epoch0，记录每次选择和实际 epoch 数。

这些内部开发选择属于新增研究消费，不能声称完全未选模；已有外部开发 validation 的模型消费次数保持为1，本卡拟议新增外部模型评估为0。四个配置最多各61个 checkpoint 候选，实际选择计数按日志登记，不与独立实验次数混写。

## 指标和停止条件

报告40个组的 MAPE、MAE、WAPE、零数、最差组、共同样本和缺失覆盖；正值误差分层与常态偏差同时报告，不能只选总体 MAPE 最小的臂。各损失及 L3 分项的量级、梯度占比、训练耗时、checkpoint 选择、raw/final 输出与哈希全部保留。不能以低值标签作线上状态或从开发集学习常数收缩/校准参数。

原研发约束保留：相对同骨干 L0 的节点宏 MAPE 至少改善5%，最差组与各负载节点宏 MAE 退化不超过5%；这些只用于研发筛选，不代表正式达标或跨轮稳定。若所有臂仅靠压低预测改善 MAPE 且常态 MAE/WAPE 恶化，保留权衡，后续训练内常数收缩对照另卡处理，不能立即扫权重、δ、τ或阈值。

拟议一个 B 作业顺序执行四个配置，**整组总硬预算不超过1800秒**，CPU4/workers0、仅启动时空闲的 B UUID GPU；使用共享旧门锁和独占 UUID/owner 锁。不能把每臂1800秒混成总预算。代码/数据/初始化/划分/预处理不一致、资源冲突、超时或非有限值时停下并保留 partial，不自动续跑或扩大预算。

本卡没有可直接启动的命令或 job_id。实际代码尚未完成，完整可复现配置、参数量及归一化/mask 审查仍是前置；不得把草案写完当作获准跳过这些步骤。部署前还需另测冻结候选的 CPU 特征+推理、真实到达与发布链路，不能把训练 GPU 速度当部署成本。
