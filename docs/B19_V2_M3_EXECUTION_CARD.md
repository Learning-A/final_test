# V2-M3 短因果卷积对照

本卡已完成，标记 `completed_no_gain / do_not_repeat`。 [实际结果](B19_V2_M3_RESULTS.md)

M1 和 M2 都未达到 5% 的相对改善门槛。M3 沿用冻结的 R2 L0 基线，检验对相同 20 个 100 ms 名义槽进行因果卷积是否有增益。原 258 维输入、八节点、5,328/2,661 秒共同键、源时钟 S−80 ms 截止和 R2 预处理均复用。

将原 100 个短时字段按时间从旧到新排列，每槽包含读、写、总操作数、观测标记及 age。三层卷积各有 32 通道，卷积核宽度为 3，膨胀率依次为 1、2、4。每层分别在左侧填充 2、4、8 个位置，单个末端输出感受野为 15 槽。对 20 个位置的输出按原观测标记取掩码均值，所有槽缺失时短时输出为零。保留原 144 维历史输入、14 个短时摘要及覆盖字段和 4 维节点嵌入，再接两层 64 单元共享网络。短时分支共 23,457 个总参数，原骨干为 21,089 个。差异归于整套时序分支。

复用原目标尺度、L0 缩放 MAE、批次与样本权重、seed2026、AdamW、梯度和内部选模规则。预测初始化复现原 epoch0 输出。单次新拟合，B 专属 GPU，CPU4、workers0，独立任务硬预算 1,800 秒，使用既有租约。仍按原 5% 宏 MAPE 改善、最差组及各负载平均节点 MAE 相对退化至多 5% 和共同键覆盖筛选。记录每轮得分、冻结预测、权重和租约。
