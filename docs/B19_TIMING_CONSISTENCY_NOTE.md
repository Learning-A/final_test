50 ms 是评分前固定的源时钟假设，含义为输入截止 C=T−30ms−50ms。现有 100 个 Graph train03 固定样本的预索引组件计时 P95 为 53.011 ms，其中九模型串行调用 P95 为 48.596 ms、特征构造 P95 为 4.661 ms。分量各自的分位数不能直接相加；联合计时的 53.011 ms 才是这项观测。测量不包含数据到达、网络、发布或完整服务调度。

因此，主档的 9.26% 节点宏 MAPE 相对改善只保留为源时钟条件下的离线输入证据。当前组件耗时已超过其假设处理余量；即使组件更快，也不能补齐未知的逐轮时钟误差和模型服务收到时间。

100/200 ms 档没有复现主档的研发筛选收益。不得从中再挑一个好看的余量、修改正式 MAPE、过滤低值或删除迟到样本来获得通过。

后续卡先区分两个问题。第一是冻结九个树模型的执行链是否能在不改变预测的前提下降低 CPU 开销；这类工作需要预登记硬件、线程上限、固定样本和输出等价检查，可以复用权重，不拟合。第二是轻量共享骨干是否能兼顾输入收益与成本；这属于新的模型配置，必须另登记同样本、同输入、固定损失、容量和总预算，不能当作旧树模型的重做。

本轮不执行上述候选卡。进入损失 L0–L3 或模型比较前，先写清可用输入的离线范围、时间假设及失败判据；A 的指标复核通过不能代替线上时间资格。两卡并行锁规则继续有效，不为占用空闲 GPU 而启动实验。
