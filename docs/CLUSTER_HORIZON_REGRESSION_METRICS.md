合并指标衡量混合任务总体的绝对量级区分，具有明确数学定义，不是算错；但它包含业务间水平差异，不能代表每个业务内部随时间的预测能力。数据中Graph、AI、Baleen/WRF的平均水平不同，分清这些水平就能让混合R²/r较高。若未来只报告合并值，必须说明任务总体和负载混合比例，同时保留组内结果，不能以0.983相关解释成98.3%点预测准确。

WRF存在较强阶段趋势：本次10秒窗口r达到0.9033，而R²仍为0.6735且平均高估149.17 IOPS，说明趋势相关和数值校准是两件事。其余若干负载组内相关接近0，支持“本卡主要估计负荷水平、没有充分跟随组内变化”的判断；不能仅由弱相关证明这些变化没有可用先兆或所有模型都不可预测。

## 四个指标分别说明什么

- MAE=mean(abs(pred−actual))，保留IOPS单位，描述平均绝对偏差。
- RMSE=sqrt(mean((pred−actual)²))，也保留IOPS单位，大偏差受到更重惩罚。本次RMSE明显大于MAE，说明尾部误差较重要；二者都不是百分比准确率。
- 预测R²=1−SSE/SST，其中SST=sum((actual−该组实际均值)²)。负值说明平方误差高于这条留出组均值参照，不能只看曲线是否跟随。更长窗口实际波动变小，虽然绝对误差也下降，残余偏差相对于组内方差可能更大，所以R²可以变得更负。
- Pearson r衡量中心化后线性共同变化，范围[−1,1]，对平移及正比例缩放不敏感。例如pred=2×actual+100可以r=1但数值误差很大。它不能直接换成百分比准确率。

**预测R²通常不等于Pearson r的平方。** 只有带截距的一元最小二乘回归在其样本内等特定条件下才有此关系；当前神经预测和留出评分不满足这一等式的前提。

同一固定起点的第10个单独秒，直接路线MAE709.733、RMSE1187.673、R²−0.0400、r0.1310；fine路线MAE717.207、RMSE1201.564、R²−0.0678、r0.1279。这里再次区分“第10秒”与“前10秒平均”。
