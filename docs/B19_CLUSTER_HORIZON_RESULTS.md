## 主要结果

指标为五负载各自WAPE后等权平均，越小越好；展示分数=100−WAPE%。同一个模型、同一预测时刻输出所有期限，不按每个期限重新挑模型。

本卡中，直接整秒路线四个窗口的宏WAPE均较低。100ms路线并没有因为先预测更多桶而提高聚合精度。差距来自本卡目标粒度及其训练约束的整体变化，不能仅据一次单seed实验断言100ms分解永远无效。

未来10秒窗口均值并不是第10秒IOPS。模型对第10个单独秒的宏WAPE为直接整秒18.3908%、100ms聚合18.5938%，明显高于对应10秒均值的11.2177%和12.0645%。更长窗口平均可以抵消部分时间上的正负偏差，也减少瞬时低谷在整窗比例误差中的影响；不表示远期逐秒轨迹反而更容易。

输出轨迹本身很平滑。按2297起点各自10秒内的标准差再取中位数，真实值为684.97 IOPS，直接预测为0.61、fine聚合为2.96 IOPS；实际相邻秒绝对变化平均942.73 IOPS，而预测为0.24/0.72 IOPS。该描述没有重新选模或拟合，见[轨迹诊断](../reports/cluster_horizon_trajectory_diagnostics.json)。说明本卡主要给出随输入条件变化的负荷水平，未能表达真实未来逐秒起伏；不证明这些起伏一定不可预测。此处是同容量小型共享时间decoder的有界pilot，不能据此否定所有序列到序列或100ms模型。诊断文件是最终包冻结后的补充分析，原ZIP不覆盖改写。

直接整秒的10秒窗口只有Graph一个负载超过90分，Baleen较接近；五负载等权仅88.78分。原MAPE仍报告：直接路线1/3/5/10秒窗口分别256.2245%、17.6382%、14.3683%、12.0381%；100ms路线分别259.7342%、18.2262%、15.1285%、12.9349%。原MAPE不能被WAPE补分覆盖，也不能用10秒任务替代此前要求的1秒成绩。

直接路线四窗口的MdAPE分别7.8138%、8.5370%、9.2274%、9.4665%，虽然补成典型精度均超过90，但其±20%命中率分别75.95%、72.54%、75.99%、81.86%。这再次说明“典型误差补分90”不等于九成窗口预测正确。

## 实验如何保证可比

- 所有输出在源时钟假设截止S−80ms一次产生，不读取后续真实输入滚动修正；未来真值仅用于标签与评分。
- direct_seconds一次输出10个1秒IOPS；fine100ms一次输出100个100ms桶IOPS速率，每10个取平均得到对应1秒值。四个窗口均值由前H个秒平均；总操作数=均值×H，均存入预测行。
- 历史输入为冻结cluster1840；原R2训练尺度仅做应用，无本机归一化拟合。两臂124161个参数、相同初始权重hash、batch排列hash、训练集群尺度3173 IOPS、run等权、优化器及早停规则，独立核验全部一致。共享decoder接收固定时间/宽度坐标，所以输出数量不增加学习参数。
- 按五负载×四累计窗口WAPE选checkpoint。直接最佳epoch7、训练13轮、14次评分；fine最佳epoch2、训练8轮、9次评分。只跑一个seed，不按期限或负载挑不同模型拼接。
- 从原5328/2661起点按完整10秒标签条件固定4615拟合/2297内部开发起点。未来有缺桶或超过本轮范围则排除，保留每轮原因；未按误差或低值筛选，未补零。所有期限使用相同起点，较长窗口覆盖条件本身会改变样本分布。
- 69120个带重复未来秒标签（6912起点×10秒）与原sealed host windows逐一一致。这里是标签使用次数，不是69120个独立秒；相邻预测起点有重叠目标窗口，不能当独立重复实验计算显著性。

旧R1直接集群头在本卡2297个共同起点的1秒WAPE为19.0996%，直接新路线为17.8310%；本卡改变了网络、训练样本、输出任务和选模指标，不能把这项差异全部归因于直接整秒训练。冻结last-complete-second持久参照在1/3/5/10窗口WAPE分别26.9785%、22.9824%、22.1458%、21.5097%，两条新路线均优于这一参照。
