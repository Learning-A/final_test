# R1 近端输入的离线时间敏感性

基于已发布的 15 轮训练数据，检查每个有效节点标签之前 2 秒内的 20 个名义 100 ms 桶。标签限定在各轮记录起点后 16 至 600 秒，合计 69,820 个有效节点窗口。该统计用于检查覆盖率，范围包含完整的单节点标签。模型对照继续使用 B 已固定的共同样本。

有效桶须满足桶结束时间和源端读取结束时间均早于或等于输入截止。输入截止设为目标秒前 30 ms 再减下表中的额外余量。额外余量是敏感性分析参数。逐轮跨机时钟误差上界未知，线上推理端接收时间缺失。

| 额外余量 | 平均可用桶数 / 20 | 最近 500 ms 至少一个桶的比例 |
| --- | ---: | ---: |
| 0 ms | 18.993 | 100.0000% |
| 50 ms | 18.992 | 100.0000% |
| 100 ms | 17.993 | 99.9986% |
| 200 ms | 16.994 | 99.9771% |
| 500 ms | 13.995 | 0.0000% |

所有情景下，每个有效节点窗口均保留至少一个桶。结果支持在源时钟假设下比较 50、100 和 200 ms 等输入余量。近端信息是否降低预测误差，仍由固定的 F0 和 F0+F1 对照决定。正式发布时延和跨机边界仍需现场证据。

复现脚本为 `scripts/audit_r1_timing_coverage.py`。输入取 [R1 发布页](https://github.com/Learning-A/final_test/releases/tag/r1-train-core-100ms-20261122-v1) 的索引和核心数据，以及索引引用的 Graph 样例和 [20 轮发布页](https://github.com/Learning-A/final_test/releases/tag/development-all-20-rounds-20261122-v1) 的原训练包。逐轮结果在 `reports/r1_timing_coverage.json`。
