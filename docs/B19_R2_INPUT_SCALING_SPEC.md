# R2 258 维输入与训练内尺度规格草案

`r2_scaling.py` 已实现本规格。字段顺序来自 `masked_inputs.py`、`multiscale_inputs.py` 和 `fine_inputs.py`，合成样本已核对全部 258 个字段名。索引为从 0 开始的半开区间。

| 字段组 | 索引 | 数值处理 | 观测条件 |
| --- | --- | --- | --- |
| 必需5秒读写总量 | [0,15) | 训练连续尺度 | 原构造器已要求完整、及时 |
| 必需5秒三分量的 mean/std/min/max/median | [15,30) | 训练连续尺度 | 同上 |
| 三分量差分 | [30,33) | 训练连续尺度，保留符号 | 同上 |
| 最新读比例、总量为零标记 | [33,35) | 原样保留 | 比例的真实零仍为合法值 |
| 可选15秒 lag 的三分量 | 每 lag 起点 35+4×(lag−1)，前三列 | 仅观测位置参与训练尺度；缺失变换后恢复占位0 | 起点+3 的 observed 必须为1 |
| 可选 lag 的 observed | 每 lag 起点+3 | 0/1 原样保留 | 明确 mask，不从计数是否为0推断 |
| 可选长历史三分量各5个摘要 | [95,110) | 训练连续尺度 | 已接受样本至少有必需短历史对应的观测；仍断言覆盖>0 |
| 长历史覆盖、最早观测 lag 秒数 | [110,112) | 比例/秒数原样保留 | 覆盖必须>0 |
| 8节点空间三分量 | 每节点起点112+4×node，前三列 | 仅观测位置参与训练尺度；缺失恢复占位0 | 起点+3 的 observed=1 |
| 空间 observed | 每节点起点+3 | 0/1 原样保留 | 与节点顺序一起固定 |
| 20个 fine lag 的读写总计数 | 每 lag 起点144+5×(lag−1)，前三列 | 仅观测位置参与训练尺度；缺失恢复占位0 | 起点+3 的 observed=1 |
| fine lag 的 observed/age秒 | 起点+3/+4 | mask、秒数原样保留，未观测 age=0 | 原 fine 时序检查保留 |
| fine 总覆盖/最近观测 age秒 | [244,246) | 原样保留；无桶 age=0 | 总覆盖为0时 age 不当真实最近活动 |
| 最近3/5/10/20槽的观测计数和 | 246+3×i | 训练连续尺度；无观测恢复占位0 | 其后 observed_fraction>0 |
| 同组覆盖/观测零比例 | 247+3×i、248+3×i | 比例原样保留，缺失由覆盖区分 | 不把无观测的零比例当实际全零 |

拟议对连续列按所有拟合样本及8节点汇总观测位置，计算训练均值和总体标准差（ddof=0），尺度为 max(std,1)。真实观测零参与，缺失占位不参与。一个连续列完全没有观测时记录 count=0、中心0/尺度1，并保持其输出占位0；后续内部开发出现该列真实观测时只用冻结中心/尺度，不回拟合。所有臂使用同一份统计。此方案不对比例、mask、age 拟合尺度，既有时间和单位语义保留。

输出训练尺度按节点固定：s=max(1,正标签中位数)，τ=max(1,正标签第10百分位)，分位数采用 NumPy `method='linear'` 的明确版本语义。每个节点只使用拟合角色标签，若没有正值则停止本卡；不在本机计算这些数。

共享 MLP 的实现拟议固定为输入258+embedding4、ReLU 两层 hidden64、标量 softplus 输出乘节点 s。参数量为21,089（含8×4 embedding）。为使四损失 epoch0 一致，最后一层权重置0、bias为 inverse-softplus(1)，因此 epoch0 输出为节点训练尺度；其余权重及 embedding 使用同一 seed2026 初始化。这里的尺度和初始化都未实际拟合或执行。

样本单位为一个时间键的一个节点。每拟合 run 的每节点样本权重为 1/(10×该run有效秒数×8)，全体权重和为1；五类各有两个拟合 run，因此类别和 run 等权。小批目标采用 N×mean(weight×loss)，与完整加权目标的随机梯度期望一致，N为全部拟合节点样本数。固定相同 shuffle 序列和最后一批处理，各臂不使用开发集确定权重。

字段契约 SHA256 为 `faf89520c65b69e630d27a9ad0fb8165175c21617b5b0868a669964219c7e550`，固定字段名、观测映射和节点顺序。变换入口先核对字段顺序，再区分真实观测零与缺失占位。七项功能检查使用合成特征和手写统计，覆盖字段顺序、掩码、真实零、连续列的默认值、轮次权重，以及非训练主机和错误数据角色的拒绝。实际统计是后续 R2 作业的一部分，拟合入口限 b507 上的 `train` / `fit_run01_02`。
