# V2-M1：固定 C 的历史尺度与残差对照

2026-11-23。状态：`specification_frozen_before_fit`。用户已授权执行V2。D0确认普通阶段仍有显著误差；D1已验收，I1新增bytes/pressure未达到门槛且A已独立复核。按V2固定原258维C，不追加辅助输入、损失或seed搜索。本卡仅一个新增网络配置；M0直接复用R2 L0。

## 固定假设与可归因范围

假设：用已知历史量级作初始参考，并学习按局部波动缩放的修正，可能减小普通窗口量级偏差。它同时改变输出表示、初始化和四个历史描述量，因此即便有效，也只说明整套变换有效；不能单独归因于尺度、宣称RevIN复现或负迁移已解决。前置证据不保证达标。

样本与时间仍为原10轮拟合、5轮train03内部开发，5,328/2,661共同秒、八节点下一秒total。输入截止S−80ms，源时钟额外50ms仅离线假设，线上接收/时钟界仍未知。不得删正低值、补标签或使用目标同秒输入。

## 数据、尺度与模型

1. C保持原R2的完整258维、mask与age、顺序及源时间谓词。复用I1输入包中已经核对的C矩阵，B/P不送入M1。原R2全局输入中心/尺度和每节点目标尺度s原样复用；它们由原拟合轮在b507计算，不能重拟合或读取train03修正。
2. 每节点只取C中五个必需完整历史秒的total列 `[2,5,8,11,14]`，最新为 `[S−2s,S−1s)`。这五秒本来已完整且按时，不从可选缺失历史估计局部量级。令m为五值均值、σ₀为总体标准差ddof=0，b=max(m,1 IOPS)，σ=max(σ₀,1 IOPS,0.05s)。窗口5、0.05及1IOPS下限在评分前固定，不扫窗口或floor。历史全零时b=1、σ沿固定下限，另加zero_history=1；没有把缺失当全零。
3. 在原全局尺度变换后的C追加四列：`b/s`、`σ/s`、`(latest−m)/σ`、`m==0`。原C不重新减去局部均值，不把所有258维或fine计数混当可逆目标通道。四描述量只从历史与已保存训练尺度计算，没有新增参数估计。
4. 输入262维加原node embedding4，仍两层64 ReLU、标量有符号δ头。预测为 `max(0,b+σδ)`。最后一层权重和偏置置0，所以epoch0预测为b，而非原M0的常数s。其他参数以seed2026初始化，构造器不推进外部随机状态。参数量21,345，比原R2的21,089多256；容量差异公开，默认只解释整套方法。
5. M0的R2 L0冻结预测、checkpoint选择和预处理原样复用。M1沿原L0缩放MAE：每节点误差除以同一s，十个拟合run等权、节点等权；真实零进训练与MAE。模型输出可以为真实0，正式MAPE仅排实际零，不能排预测零。
